# Gen1BetterSprites 🎨

Gen1BetterSprites is a Gen1Recomp mod that locally derives Pokémon artwork from user-supplied Pokémon Gold, Silver, and Crystal ROMs. The repository does **not** contain extracted or ROM-derived image assets. Still working on animations

## Importing ROMs 📦

1. Open Gen1Recomp's **Mod Manager**
2. Select **Gen1BetterSprites**
3. Open **Imported Files**
4. Import your Pokémon Gold, Silver, and/or Crystal ROM
5. Start or restart the game after importing

ROMs must be clean versions recognized by Gen1Recomp. The mod reads them locally and does not include or distribute their contents.

## Settings ⚙️

Open **Options > BetterSprites** in game

- **Sprite Source** — Defaults to **GEN1**. Gold, Silver, and Crystal are only shown after the matching ROM has been imported. Restart after changing it
- **Menu True Color** — Controls imported sprites outside of battle
- **Battle True Color** — Independently controls imported battle sprites ⚔️
- **Global Palettes** — Optionally assigns the selected ROM's Pokémon palettes to Gen1Recomp's normal Pokémon palette system. Restart after changing it. 🎨

All derived sprite data is generated locally from the player's imported ROM and stored only in Gen1Recomp's local mod cache 🔒
